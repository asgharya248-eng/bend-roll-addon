Tut Bend Effect

Geometry Nodes Bend & Roll — Blender Addon

Overview

Tut Bend Effect is a procedural bend and roll deformation built entirely with Geometry Nodes. It lets you bend, curl, and roll any object along a control path — meshes, curves, text, and more — fully non-destructively.

Key Features

  • Bend & Roll — curl any geometry along a NURBS control path with a rolling twist along the axis.
  • 100% Geometry Nodes — ships the exact node trees from the source .blend; every link and value is untouched.
  • Non-destructive — applied as a modifier, so the original mesh never changes. Remove it anytime.
  • Works on anything — mesh, curve, surface, meta, text, point cloud, volume, and grease pencil objects.
  • Editable nodes — open the original node tree in the Geometry Nodes editor and tweak anything live.

How to Use

  1. Select an object in the 3D viewport.
  2. Open the sidebar (N) and find the Tut Bend tab.
  3. Click Add Tut Bend Effect — the modifier is added.
  4. Edit the NurbsPath control object to shape the bend and roll.
  5. Use Open Node Editor to expose and animate every parameter.

Requirements

  • Blender 5.2 or newer
  • Installed as an extension (drag & drop the ZIP, or Install from disk)
